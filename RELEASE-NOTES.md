# YUZ-TRA 1.5.46 — Version Officielle WordPress.org

Télécharger **yuz-tra-1.5.46.zip** ci-dessous (ou depuis le répertoire officiel WordPress.org : https://wordpress.org/plugins/yuz-tra/).
La somme SHA-256 est jointe. Le ZIP contient le dossier `yuz-tra`, directement
installable depuis Extensions → Ajouter → Téléverser dans WordPress.

### Nouveautés 1.5.46 :
* **Adaptateur Youzurz Cloud (TRS)** : raccordement direct au moteur souverain via passerelle sécurisée `https://tra.youzurz.com/api/v1/translate`.
* **Bandeau d'Onboarding Conforme WordPress.org** : respect strict des directives §7 et §11 (opt-in explicite dé-coché par défaut, dismissible, sans création automatique silencieuse).
* **10 000 mots offerts** : provisionnement immédiat de crédits de traduction pour traduire pages et fiches produits sans installer de serveur.
* **Maintien des Moteurs Locaux** : préservation intégrale des configurations existantes (LibreTranslate, Ollama, DeepL, Google).

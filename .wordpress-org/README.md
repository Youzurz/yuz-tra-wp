# WordPress.org assets

Put plugin-directory assets in this folder so CI can copy them to the SVN top-level `assets/` directory.

Expected filenames:

- `banner-772x250.png`
- `banner-1544x500.png`
- `icon-128x128.png`
- `icon-256x256.png`
- `icon.svg` optional
- `screenshot-1.png`
- `screenshot-2.png`

All filenames should be lowercase.
